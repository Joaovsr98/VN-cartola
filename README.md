# VN Cartola / VN Arena

Protótipo independente de gestão de ligas fantasy para 2027. Dados fictícios, pagamentos desativados, sem integração externa autorizada nesta etapa.

Base v0.2.0. Node.js 22.13+ e SQLite local. Execute `npm test` para os testes e `ADMIN_PASSWORD='senha-local-forte' npm start` para iniciar o servidor após inclusão do código. Não inserir dados reais. PostgreSQL, multi-tenant e integração autorizada são etapas futuras.
